# Evaluation Scorecard & Ranked Issue List

**Version:** v0.1.0 (MVP)  
**Evaluator:** Principal Engineer, Product QA Lead, Security Reviewer  
**Date:** November 2026

## 1. Dimensional Evaluation (1–10 Scale)

| Dimension | Score (1-10) | Concrete Evidence | Top Fix |
| :--- | :---: | :--- | :--- |
| **1. Requirement Coverage & Correctness** | **6 / 10** | 1. `codeExporters.ts` hardcodes `RecursiveCharacterTextSplitter` regardless of active algorithm (`markdown`, `fixed`, `sentence`).<br>2. `markdownChunker.ts` splits code blocks containing blank lines or exceeding `chunkSize`, breaking code fences in half.<br>3. `sentenceChunker.ts` does not enforce `chunkSize` when a sentence exceeds the limit, emitting oversized chunks. | Make code exporters strategy-aware, protect code blocks with unified sub-chunking, and enforce `chunkSize` limits across all chunkers. |
| **2. Architecture & Modularity** | **8 / 10** | 1. Clean separation between engine (`chunkers`, `tokenizers`, `types`), components, data, and exporters.<br>2. `executeChunking` provides a clean unified facade with uniform timing and metric extraction.<br>3. Token-aware and character-aware text truncation/slicing is re-implemented in multiple files rather than reusing a shared helper. | Centralize text/token slicing and boundary detection into `src/engine/chunkers/utils.ts`. |

Unused dependencies in `package.json`: `clsx` and `tailwind-merge` are installed but never imported.<br>3. `indexOf(chunkStr)` without forward search offset in `markdownChunker` and `sentenceChunker` produces incorrect `startCharIndex` on repeated sentences. | Remove dead code and unused dependencies; wire standard `cn` helper if needed; fix offset tracking using running cursors. |

Zero automated tests for `codeExporters.ts`, `ComparisonView`, token-unit mode, or error conditions.<br>3. Loose assertions: `chunkers.test.ts:56` checks `expect(c.charCount).toBeLessThanOrEqual(100)` for a chunker configured with `chunkSize: 80`. | Expand unit test suite with 100% coverage of all 4 chunkers (chars & tokens), code exporters, and edge cases. |
| **5. Security** | **9 / 10** | 1. 100% client-side execution ensures zero document leakage over the network.<br>2. No external server dependencies, no API keys, no auth vulnerabilities.<br>3. No `dangerouslySetInnerHTML` usage; React safely escapes chunk text. | Add file upload size guards and mime/extension sanity checks in `ControlsPanel.tsx` to prevent main-thread denial of service. |
| **6. Reliability** | **6 / 10** | 1. `FileReader` in `ControlsPanel.tsx` lacks `onerror` handling.<br>2. When `chunkSize` is reduced below `chunkOverlap`, `chunkOverlap` is not clamped, causing overlap > size.<br>3. Tokenizer fallback to `cl100k_base` and character heuristic works, but failures are not logged cleanly to user UI. | Auto-clamp `chunkOverlap` upon `chunkSize` reduction, add file reader error handling, and guard against non-positive chunk dimensions. |
| **7. Performance & Scalability** | **5 / 10** | 1. Production bundle size is 5.8 MB because `js-tiktoken` dictionaries are bundled in a single file.<br>2. Synchronous tokenization on the main thread during high-frequency slider changes.<br>3. `useMemo` in `App.tsx` prevents unnecessary recalculation, but slider dragging lacks debouncing. | Optimize Rollup manualChunks configuration to split tiktoken vendor assets, and debounce rapid slider inputs. |
| **8. Data Integrity** | **7 / 10** | 1. `MetricsBar.tsx` computes embedding cost and token count from raw text rather than total chunk tokens (underreporting overlap cost).<br>2. `markdownChunker` sets `overlapPrevChars: chunkOverlap` in metadata despite executing zero actual overlap.<br>3. Fixed token chunker sets `startCharIndex: -1` and mislabels token overlap as characters in UI. | Fix total chunk token summation and true overlap reporting in chunk metadata and metrics. |
| **9. UX / DX** | **7 / 10** | 1. Modern developer-centric dark UI, crisp typography, and responsive cards.<br>2. Continuous stream view duplicates overlapping text consecutively rather than highlighting boundaries cleanly.<br>3. Missing standalone `typecheck` and `lint` npm scripts in `package.json`. Comparison view lacks unit/overlap controls for Variant B. | Refine continuous stream view to highlight overlaps with `.overlap-highlight`, expand Variant B controls, and add DX npm scripts. |
| **10. Operability** | **6 / 10** | 1. Fast static build ready for zero-cost static hosting (Cloudflare Pages, Vercel).<br>2. Missing CI/CD pipeline (`.github/workflows/ci.yml`) to enforce tests and type checks on PRs.<br>3. Discrepancy between README claims (PDF, Umami) and deployed assets. | Add GitHub Actions CI workflow and align documentation with actual repository capabilities. |

## 2. Ranked Issue List

**Scoring Formula:**  
`Rank = (Impact [1–4] × PRD Priority [1–3]) ÷ Effort [1–3]`  
- Impact: Critical = 4, High = 3, Med = 2, Low = 1  
- Priority: Must = 3, Should = 2, Could = 1  
- Effort: Small (S) = 1, Medium (M) = 2, Large (L) = 3  

| ID | Issue | Severity | Impact | Priority | Effort | Score | Evidence | Proposed Fix |
| :---: | :--- | :---: | :---: | :---: | :---: | :---: | :--- | :--- |
| **ISS-01** | **Overlap Slider Desync & No Clamping** | High | 3 | Must (3) | S (1) | **9.0** | Lowering `chunkSize` leaves `chunkOverlap > chunkSize`, causing invalid step calculations. | Automatically clamp `chunkOverlap = Math.min(chunkOverlap, Math.floor(newChunkSize * 0.5))` in `ControlsPanel.tsx` and enforce safeguards in chunkers. |
| **ISS-02** | **RAG Cost & Token Metrics Underreporting** | High | 3 | Must (3) | S (1) | **9.0** | `executeChunking` calculates cost from `totalTokens` (raw text) instead of `totalChunkTokens` (sum of chunk tokens with overlap). | Calculate and display both Source Document Tokens and Total Chunk Tokens (Ingestion Tokens) and base vector cost on total chunk tokens. |
| **ISS-03** | **Code Exporter Ignores Selected Strategy** | High | 3 | Must (3) | M (2) | **4.5** | `codeExporters.ts` hardcodes `RecursiveCharacterTextSplitter` for LangChain and `SentenceSplitter` for LlamaIndex for all strategies. | Implement strategy-specific exporters for Markdown (`MarkdownHeaderTextSplitter`), Sentence (`SentenceSplitter`), Fixed (`CharacterTextSplitter`), and Recursive across all 4 frameworks. |
| **ISS-04** | **Markdown AST Chunker Breaks Code Fences** | High | 3 | Must (3) | M (2) | **4.5** | Paragraph splitting on `\n\s*\n` breaks code blocks with blank lines or oversized code, leaving unclosed ` ``` ` fences. Also lacks true overlap. | Track code fence boundaries explicitly during paragraph splitting; keep code blocks intact or close fences cleanly; implement real paragraph overlap. |
| **ISS-05** | **Oversized Sentences Violate Chunk Size** | High | 3 | Must (3) | M (2) | **4.5** | `sentenceChunker.ts` pushes oversized sentences without sub-splitting, creating chunks exceeding `chunkSize` by 3x-4x. | Add fallback word/token splitting for sentences that exceed `chunkSize` to strictly enforce max chunk size constraints. |
| **ISS-06** | **Inadequate Test Suite & Loose Assertions** | High | 3 | Must (3) | M (2) | **4.5** | `chunkers.test.ts` only has 6 tests; relaxes `chunkSize: 80` to 100 in assertion; zero tests for exporters, tokens mode, or edge cases. | Overhaul test suite with rigorous assertions, 100% coverage of all strategies in both tokens and chars, code exporters, and edge case resilience. |
| **ISS-07** | **Continuous Stream Duplication & Dead CSS** | Med | 2 | Should (2) | S (1) | **4.0** | Continuous stream view renders overlapping chunks repeatedly; `.overlap-highlight` in CSS is unused. | Render document text with chunk boundary markers and highlight overlapping spans cleanly using `.overlap-highlight`. |
| **ISS-08** | **Comparison View Variant B Control Gaps** | Med | 2 | Should (2) | S (1) | **4.0** | Variant B is locked to `unit: 'tokens'` and `overlap: 60`, preventing direct apples-to-apples comparison with Variant A. | Add unit, overlap, and encoding synchronization or selector controls to Variant B in `ComparisonView.tsx`. |
| **ISS-09** | **Documentation Discrepancies (PDF & Telemetry)**| Med | 2 | Should (2) | S (1) | **4.0** | README claims PDF parsing in architecture diagram and Umami telemetry, which are absent in code. | Update `README.md` to accurately reflect supported text formats and clear deployment instructions. |
| **ISS-10** | **Unused Dependencies & Dead Code** | Low | 1 | Should (2) | S (1) | **2.0** | `clsx` and `tailwind-merge` in `package.json` are unused; `truncateByTokens` and `keepSeparators` are dead code. | Utilize `clsx` and `tailwind-merge` in a utility `cn()` helper (standard in modern React/Tailwind) and wire or remove dead functions. |
| **ISS-11** | **Bundle Size Optimization (5.8 MB)** | Med | 2 | Should (2) | M (2) | **2.0** | Vite bundles entire tiktoken dictionary into main chunk exceeding 5 MB. | Configure `vite.config.ts` with Rollup `manualChunks` to split `js-tiktoken` and vendor dependencies into separate chunks. |
| **ISS-12** | **Missing CI/CD & Developer Scripts** | Low | 1 | Should (2) | S (1) | **2.0** | Missing `.github/workflows/ci.yml` and `npm run typecheck` in `package.json`. | Add GitHub Actions CI workflow file and add `typecheck` script to `package.json`. |
